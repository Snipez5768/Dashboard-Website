Offline noch nicht möglich

Diese Seite läuft über http. Dabei gibt Safari ihr keinen Zwischenspeicher — sobald der Rechner aus ist, bleibt die App leer. Einmal einrichten, dann läuft sie auch ohne Rechner:

  1. Zertifikat laden und im Profil bestätigen
  2. Einstellungen → Allgemein → Info → Zertifikatsvertrauens­einstellungen → „Life OS Lokal" einschalten
  3. Sichere Adresse öffnen
  4. Dort Zum Home-Bildschirm hinzufügen — das alte Symbol kann weg
